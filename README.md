# DentalCare — Lab 6 (API Client)

Учебный сайт стоматологической клиники. Раздел услуг — статическая демонстрация дизайна; информационная лента использует **тестовые публикации** из JSONPlaceholder. Это не реальные медицинские советы или записи клиники.

## API

- **JSONPlaceholder** — https://jsonplaceholder.typicode.com
- Base URL: `https://jsonplaceholder.typicode.com`
- `GET /posts?_limit=9` — список записей
- `GET /posts?userId=2&_limit=9` — поиск по автору через query parameter
- `GET /posts/1` — детали по ID
- `GET /users` — данные авторов

## Как работает код

`fetch()` отправляет запрос к серверу и возвращает Promise. `await` ждёт результат Promise внутри `async` функции, чтобы мы могли удобно работать с ответом. Мы проверяем `response.ok`, потому что `fetch()` не выбрасывает ошибку автоматически при HTTP 404 или 500. `try/catch` позволяет показать понятную ошибку пользователю, а `finally` возвращает кнопки в рабочее состояние. `Promise.all()` одновременно загружает записи и авторов, затем оба результата показываются вместе.

## Проверка

1. Откройте `index.html` в браузере с интернетом.
2. Проверьте карточки, выбор автора, кнопку «Подробнее».
3. В DevTools → Network убедитесь, что отправляются запросы `?userId=...`, `/posts/{id}`, `/users`.
4. В DevTools → Network → Offline проверьте ошибку загрузки.
